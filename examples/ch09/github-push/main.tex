% GitHub push commands for a LaTeX project
% This file documents the shell commands (not LaTeX code) for
# connecting a local Git repository to GitHub and pushing changes.

# ---- Step 1: Create an empty repository on GitHub ----
# Go to https://github.com/new and create a new repository.
# Do NOT initialize with README or .gitignore (you'll add these locally).

# ---- Step 2: Connect your local repo to GitHub ----
git remote add origin https://github.com/username/repo-name.git

# ---- Step 3: Rename the default branch to 'main' ----
git branch -M main

# ---- Step 4: Push for the first time ----
git push -u origin main

# ---- Step 5: Subsequent pushes (after commits) ----
git add .
git commit -m "Update chapter 3"
git push

# ---- Useful remote commands ----
git remote -v              # show remote URLs
git remote remove origin   # disconnect from GitHub
git clone <url>            # clone a repo to your machine
