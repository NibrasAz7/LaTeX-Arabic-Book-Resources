% Git branch workflow for a LaTeX project
% This file documents the shell commands (not LaTeX code) for
% working with branches in a LaTeX book or thesis project.
% Useful for experimenting with new chapters without affecting
# the main version.

# ---- Create a new branch for an experimental chapter ----
git checkout -b experimental-chapter

# ---- Work on the chapter ----
# Edit your .tex files normally in your editor...
# Then stage and commit your changes:
git add chapters/chapter-experimental.tex
git commit -m "Add experimental chapter draft"

# ---- Switch back to the main branch ----
git checkout main

# ---- Merge the experimental branch into main ----
git merge experimental-chapter

# ---- Delete the branch after merging ----
git branch -d experimental-chapter

# ---- Alternative: keep the branch for future work ----
# Just don't delete it. Switch between branches with:
git checkout main           # back to main
git checkout experimental-chapter  # back to experimental

# ---- List all branches ----
git branch
git branch -a    # include remote branches
