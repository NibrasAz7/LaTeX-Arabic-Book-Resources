% Example: Piecewise functions with \begin{cases}
% Demonstrates how the cases environment typesets functions defined
% by different expressions on different domains.
\documentclass[12pt, a4paper]{article}
\usepackage{amsmath, amssymb, amsthm}
\usepackage{fontspec}
\begin{document}

\section*{Piecewise Functions with \texttt{cases}}

The absolute value function:

\[
  |x| =
  \begin{cases}
    x  & \text{if } x \geq 0 \\
    -x & \text{if } x < 0
  \end{cases}
\]

The sign function:

\[
  \operatorname{sgn}(x) =
  \begin{cases}
    1  & \text{if } x > 0 \\
    0  & \text{if } x = 0 \\
    -1 & \text{if } x < 0
  \end{cases}
\]

The Heaviside step function:

\[
  H(x) =
  \begin{cases}
    0 & \text{if } x < 0 \\
    \tfrac{1}{2} & \text{if } x = 0 \\
    1 & \text{if } x > 0
  \end{cases}
\]

A piecewise-defined polynomial:

\[
  f(x) =
  \begin{cases}
    x^2      & \text{if } x \leq 1 \\
    2x - 1   & \text{if } 1 < x \leq 3 \\
    x + 5    & \text{if } x > 3
  \end{cases}
\]
